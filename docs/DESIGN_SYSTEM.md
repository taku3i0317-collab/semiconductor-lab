# DESIGN_SYSTEM.md — 技術ネットワークのウェブのデザインのルール

対象：docs/network.html（技術ネットワーク図）・docs/node.html（ノードのページ）。値は **docs/design.css** に1か所で決め、両方のページが読む。
決めた日：2026-10-20（NET-09、案 A「シンプル・白基調」。比べた案とスクリーンショットは docs/design_options/）。

## 考え方
- 使う人は「初めて来た小学生」と「理科の先生」。**読みやすさがいちばん**。授業や印刷でも使える白基調
- 飾りより中身。色・太字・枠は「意味があるとき」だけ

## 1. 文字
- 書体は **BIZ UDPゴシック**（ユニバーサルデザインの書体）。Google Fonts から読む：`https://fonts.googleapis.com/css2?family=BIZ+UDPGothic:wght@400;700`
  - フォントのファイルはリポジトリに入れない（SIL OFL で、リポジトリの CC0 とは別のライセンスのため）
  - 図（Canvas）の文字も同じ書体（design.css の `--font`）
- ドット風の書体（DotGothic16 など）は、ゲームらしさを出す所だけに控えめに（今は使っていない）
- 大きさ：本文 15px（図の上の文字は 9〜13px）／ページの見出し 20px／節の見出し 16px／小見出し 13px

## 2. 色（意味のある所だけ）
| 変数 | 値 | 意味 |
|---|---|---|
| `--ink` / `--sub` | #1a1a1a / #5f6368 | 本文 / 補足 |
| `--bg` / `--panel` / `--line` | #ffffff / #ffffff / #e3e3e3 | 地 / カード / 枠線 |
| `--accent` | #1f5fbf | リンク・ボタン・大きな数字 |
| `--hl` | #e8710a | 選んだ・光っている・道（強調） |
| `--node-tech` / `--node-done` | #5f6368 / #3c4043 | 技術の輪 / ✅ 作った技術の塗り（❓ は輪だけ） |
| `--node-prod` | #1f5fbf | モノ |
| `--node-idea` | #7b3fbf | 発見・考え方（形はひし形） |
| `--edge` | #9aa0a6 | つながりの線（1色。種類は点線の形で：理解 3-3、発見→技術 7-3） |
| `--ok` / `--warn` | #2e7d32 / #b26b00 | ✅ ゲームにある / ⚠️ 諸説・未確認 |
- **幹の違いは色にしない**。帯の名前（「幹1 冶金」など）とアイコンの形で分かるようにする
- 以前の「幹ごとの17色」「線の年の差の色分け」はやめた

## 3. アイコン
- **絵文字は使わない方向**。アイコンは同じ雰囲気の**単色のドット絵**にそろえる（色は `--icon`）
- いまは仮として、ゲームのテクスチャ（16×16）と絵文字を、形だけ1色にして表示している（図は Canvas で1色に塗り直し、カード・ページの見出しは CSS で白黒に）。本番の単色ドット絵ができたら差し替える
- 人物の肖像（自作のドット絵）はそのまま色付き（人の見分けのため）

## 4. 部品
| 部品 | 決まり |
|---|---|
| ボタン（`.btn`、カードの「詳しく見る」） | 高さ 36px 以上・角 8px・左右 14px・14px 太字 |
| 入力・選択 | 高さ 36px 以上・角 8px |
| カード（`section`・ページの見出し・図の右のカード） | 地 `--panel`・枠 1px `--line`・角 12px・内側 16px・影なし |
| チップ（ノードの小さなボタン） | 角 8px・上下 2px 左右 10px・13px |
| 図の上の箱（凡例・ヒント） | 角 8px・枠 1px |
| 余白 | 4・8・12・16・24px の段（`--gap-1`〜`--gap-5`） |
- network.html と node.html で同じ部品を使う。新しい部品を作るときは、ここに1行足してから

## 5. 図（network.html の Canvas）の決まり
- 技術＝丸（大きさは子孫の数）、モノ＝大きな丸、発見＝ひし形。✅ は塗り、❓ は輪、⛔・➖ は点線の輪
- 選んだとき：祖先は近い層ほど明るく、遠い層ほど薄く（NET-09）。祖先から選んだノードまでの道は `--hl` の太い線
- 文字は背景色のふちどり付き

## 6. 変えるとき
- 色・大きさは design.css の変数を変える（ページの中に値を直接書かない）
- 使い勝手の点検（docs/design_options/README.md の U-1〜U-15）のうち、まだ直していないものは、ここのルールに沿って直す
