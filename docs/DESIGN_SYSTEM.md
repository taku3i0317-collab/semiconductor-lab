# DESIGN_SYSTEM.md — 技術ネットワークのウェブのデザインのルール

対象：docs/network.html（技術ネットワーク図）・docs/node.html（ノードのページ）。値は **docs/design.css** に1か所で決め、両方のページが読む。
決めた日：2026-10-20（NET-09、**案 C「中間：生成りの紙・青緑のモノ・大きな見出しだけドット風」**。比べた案とスクリーンショットは docs/design_options/）。
**今後の新しいページもこのルールに従い、docs/design.css を読む。**

## 考え方
- 使う人は「初めて来た小学生」と「理科の先生」。**読みやすさがいちばん**。生成り（少し黄みの白）の紙のような地で、落ち着いて読める図鑑・本の雰囲気
- 遊びの気配は「大きな見出しだけドット風の書体」の一点だけ
- 飾りより中身。色・太字・枠は「意味があるとき」だけ

## 1. 文字
- 書体は **BIZ UDPゴシック**（ユニバーサルデザインの書体）。Google Fonts から読む：`https://fonts.googleapis.com/css2?family=BIZ+UDPGothic:wght@400;700`
  - フォントのファイルはリポジトリに入れない（SIL OFL で、リポジトリの CC0 とは別のライセンスのため）
  - 図（Canvas）の文字も同じ書体（design.css の `--font`）
- **大きな見出しだけ** ドット風の書体 **DotGothic16**（Google Fonts、`--font-pixel`）：ページの題・節の見出し・カードの題。本文・ボタン・図の中の文字は BIZ UDPゴシック
- 大きさ：本文 15px（図の上の文字は 9〜13px）／ページの見出し 20px／節の見出し 16px／小見出し 13px

## 2. 色（意味のある所だけ）
| 変数 | 値 | 意味 |
|---|---|---|
| `--ink` / `--sub` | #2b2622 / #6b6259 | 本文 / 補足 |
| `--bg` / `--panel` / `--line` | #faf7f0（生成り） / #fffdf8 / #e4dccd | 地 / カード / 枠線 |
| `--accent` | #2f6f8f | リンク・ボタン・大きな数字 |
| `--hl` | #d9480f | 選んだ・光っている・道（強調） |
| `--node-tech` / `--node-done` | #7a6f64 / #4a423b | 技術の輪 / ✅ 作った技術の塗り（❓ は輪だけ） |
| `--node-prod` | #2f6f8f（青緑） | モノ |
| `--node-idea` | #7c4dab | 発見・考え方（形はひし形） |
| `--edge` | #b6aa98 | つながりの線（1色。種類は点線の形で：理解 3-3、発見→技術 7-3、つくるのに使った道具 1-3、同じしくみ 8-3-2-3（O-019）） |
| `--ok` / `--warn` | #2e7d32 / #b26b00 | ✅ ゲームにある / ⚠️ 諸説・未確認 |
- **幹の違いは色にしない**。帯の名前（「幹1 冶金」など）とアイコンの形で分かるようにする
- 以前の「幹ごとの17色」「線の年の差の色分け」はやめた

## 3. アイコン（S-008：案 E「色付き」に決定、2026-10-20）
- **16×16 のドット絵。色は素材を表す**：11 素材（石・鉄・銅・金・ガラス・木・土・布・樹脂・シリコン・電気）× 濃い・薄い＝ **22 色**（色見本 `design_options/palette.png`、値は `tools/gen_icons.py` の PALETTE）。形は薄い色、ふちは濃い色、中の線は2つ目の素材の濃い色（電気は光る黄）
- **1つのアイコンの色は2素材まで**（にぎやかにしない）
- **画面の意味はアイコンの色ではなく丸の枠で**：青緑の枠＝モノ、茶の枠＝技術、紫のひし形＝発見。**太い枠＝ゲームで作れる（✅）、細い枠＝まだ**。丸の中は地の色（塗りつぶさない）
- ゲームのテクスチャがあるノードは、テクスチャをこのパレットに置きかえて作る（ゲームと見た目を大きく変えない）。無いノードは `docs/icon_glyphs.json` の形から作る。作り直しは `python tools/gen_icons.py` → `python tools/gen_tree_views.py`
- 絵文字は使わない
- 人物の肖像（自作のドット絵）はそのまま色付き（人の見分けのため）

## 4. 部品
| 部品 | 決まり |
|---|---|
| ボタン（`.btn`、カードの「詳しく見る」） | 高さ 36px 以上・角 6px・左右 14px・14px 太字 |
| 入力・選択 | 高さ 36px 以上・角 6px |
| カード（`section`・ページの見出し・図の右のカード） | 地 `--panel`・枠 1px `--line`・角 9px・内側 16px・下に 1px の線の影 |
| チップ（ノードの小さなボタン） | 角 6px・上下 2px 左右 10px・13px |
| 図の上の箱（凡例・ヒント） | 角 6px・枠 1px |
| 余白 | 4・8・12・16・24px の段（`--gap-1`〜`--gap-5`） |
- network.html と node.html で同じ部品を使う。新しい部品を作るときは、ここに1行足してから

## 5. 図（network.html の Canvas）の決まり
- 技術＝丸（大きさは子孫の数）、モノ＝大きな丸、発見＝ひし形。中は地の色で色付きのアイコン、✅ は太い枠、❓ は細い枠、⛔・➖ は点線の枠（S-008）
- 選んだとき：祖先は近い層ほど明るく、遠い層ほど薄く（NET-09）。祖先から選んだノードまでの道は `--hl` の太い線
- 文字は背景色のふちどり付き

## 6. 言葉（やさしい言葉＋専門の言葉を小さく）
| ページに出す言葉 | 小さく添える専門の言葉 |
|---|---|
| 本当の話 | 本物（工程・反応式） |
| これが無いと作れない | 前提 |
| 別の作り方 | 別ルート（or） |
| なぜ動くかの説明 | 理解 |
| 前提より古い技術 | 年の逆転 |
| 分野 | 幹 |

## 7. 変えるとき
- 色・大きさは design.css の変数を変える（ページの中に値を直接書かない）
- 使い勝手の点検（docs/design_options/README.md の U-1〜U-15）のうち、まだ直していないものは、ここのルールに沿って直す
