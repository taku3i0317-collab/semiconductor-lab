# MEDIA.md — ノードの画像・動画の方針（NET-10）

技術ネットワークのノードのページ（docs/node.html）に、本物の写真・昔の図・動画を見せるための決まり。

## 1. ファイルはリポジトリに入れない（リンクだけ）
- 理由①容量：画像・動画を入れるとリポジトリが重くなり、取ってくるのが遅くなる
- 理由②ライセンス：このリポジトリは全部 CC0（誰でも何にでも自由に、名前なしで使える）。ほかの人の作品のファイルを入れると、CC0 とライセンスが混ざる。リンクなら、その作品のライセンスはその作品の所に残る
- データは docs/network_meta.json の `media`（ノード番号 → 項目の並び）。tools/gen_tree_views.py が tech_network_detail.js に入れ、node.html が表示する

## 2. どこのリンクを使うか
- **ライセンスがはっきりした所だけ**：Wikimedia Commons（ファイルのページにライセンスが書いてある）が基本。ほかに、博物館・図書館が自分で公開しているパブリックドメイン（PD）・CC0 の資料
- いちばん良いのは **パブリックドメイン（著作権が切れた・法律で PD）か CC0**。CC BY・CC BY-SA も使えるが、そのときは作者とライセンスの表示が条件なので、必ず書く（node.html は作者とライセンスを必ず表示する）
- 使わない：ライセンスが書いていない画像、検索で見つけただけの画像、ニュースサイト・会社の画像（許可が無いもの）、動画サイトの「埋め込み」で広告や関係ない動画が出るもの

## 3. 子ども向けなので、載せる前に確かめる
- **内容**：怖い・痛い・暴力的なもの、事故・戦争の生々しい写真は載せない。説明（description）は子どもに分かる1文で
- **著作権**：Commons の API（`action=query&prop=imageinfo&iiprop=extmetadata`）か、ファイルのページで、ライセンス（LicenseShortName）と作者（Artist）を確かめる。確かめた日と方法を `verified` に書く（例「2026-10-20 Commons API で PD を確認」）
- 確かめられないものは載せない。あとで分かった問題は Issue（画像・動画の提案のひな形）で知らせてもらう

## 4. 1項目の形
```json
{"url": "https://upload.wikimedia.org/…/640px-….jpg", "page": "https://commons.wikimedia.org/wiki/File:…",
 "kind": "画像", "author": "…", "license": "Public domain", "description": "…（子ども向けの1文）", "verified": "2026-10-20 Commons API で PD を確認"}
```
- `url`：表示する画像（Commons は幅 640px の縮小版）または動画のファイル。`page`：出典のページ（押すとそこへ）
- `kind`：画像／動画。動画はファイル（webm・ogv・mp4）ならページの中で再生、そうでなければリンク
- `author`・`license` が無い項目は表示しない
- 1ノード1〜2枚まで
