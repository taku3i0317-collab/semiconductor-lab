\## 決まったこと ✅

\- 方針：工程の順番と理由は本物どおり。操作と時間はゲーム向けに短く。簡略化はガイドブックに正直に書く

\- 説明3段階：通常＝やさしい説明／Shift＝数値／ガイドブック＝式・歴史

\- ウェハーは「状態機械」。順番に意味がある工程は入らない（理由を表示）。意味のない工程はとばせるが欠陥が増える

\- 工程ミスの厳しさ：序盤ゆるめ → 終盤きびしめ

\- 純度：データは小数、表示は4段階（98%／6N／9N／11N）。不足時は次の機械に入らない（将来：性能低下に拡張）

\- 章のゴールは製品。部品はバニラ素材で済ませる

\- ゲルマニウム入手：石炭 →かまど→ 石炭灰 →作業台(×8+水入り瓶)→ 粗ゲルマニウム

\- 素材は c: タグに入れる（他MODとの共存）

\- GregTechとは別MOD。「学習用」を前面に出す

\## データモデル（アイテムが持つ情報）

\- material：element / purity(小数) / form(ore→metallurgical→polycrystal→single\_crystal) / dopant

\- ingot：material + diameter\_mm / defect\_density

\- wafer：diameter\_mm / dopant / surface(状態) / layers / min\_feature\_nm / overlay\_error\_nm / defects / flatness\_nm / mask\_id

\- photomask：design / min\_feature\_nm / durability

\- chip：design / node\_nm / grade(A/B/fail) / transistor\_count

\- v0.1 で使うのは material の element / purity / form だけ



\## 目玉：露光装置（第3章以降）

\- 解像度：CD = k1 × λ / NA

\- 焦点深度：DOF = k2 × λ / NA²（NAを上げるとピント範囲が狭くなる → CMPが必要）

\- 世代：コンタクト(g線436nm) → ステッパー(g線/i線365nm) → KrF 248nm → ArF 193nm → ArF液浸(NA〜1.35) → EUV 13.5nm(NA 0.33、真空＋鏡)

\- 歩留まり：Y ≒ e^(−欠陥密度 × チップ面積)
