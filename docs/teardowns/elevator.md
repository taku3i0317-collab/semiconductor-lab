# 分解シート：エレベーター（[P-34]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。出典は各ノードの本物欄

- 年：1852〜1854（オーチスの安全装置）〜1880（シーメンスの電気エレベーター）〜1903（つり合いおもり付きのギアレス巻上機）
- しくみ：人の乗るかごを鋼のロープでつり、ロープの反対側には『つり合いおもり』を下げて、モーターは差の分だけ持ち上げればよいようにしている。ロープは滑車（綱車）の溝との摩擦で動く。ロープが切れたり速すぎたりすると、安全装置がレールをはさんでかごを止める。
