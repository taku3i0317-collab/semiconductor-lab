# 分解シート：エスカレーター（[P-35]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。出典は各ノードの本物欄

- 年：1892（リノの特許）〜1900（パリ万博のオーチス・シーバーガー型）〜1921頃（今の形）
- しくみ：1892年にジェシー・リノが傾斜したベルト式の「エンドレス・コンベヤー」の特許を取り、1896年にコニーアイランドで動かした。チャールズ・シーバーガーがホイーラーの特許を買い、オーチス社と作った平らな段の型が1900年パリ万博で一等賞をとった。今の形は、リノの溝付きの段とシーバーガーの平らな段を合わせたもの。
