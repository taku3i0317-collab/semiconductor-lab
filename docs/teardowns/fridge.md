# 分解シート：冷蔵庫（[P-30]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。生成元：調べ係の確認（出典は各ノードの本物欄）

- 年：1834（パーキンスの蒸気圧縮の特許）〜1927（GE モニタートップ）
- しくみ：冷蔵庫もエアコンと同じ蒸気圧縮のしくみで、庫内の熱を後ろや横の放熱器から部屋へ捨てている。1927年の GE「モニタートップ」は、圧縮機をケースに密閉した家庭用冷蔵庫で、一般の家に広まるきっかけになった。今の日本の冷蔵庫は、冷媒にイソブタン、壁にウレタンの断熱材を使い、インバーターで圧縮機の速さを変える物が多い。
