# 分解シート：デジタルカメラ（[P-27]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。生成元：調べ係の確認（出典は各ノードの本物欄）

- 年：1975（コダックの試作）〜1990（最初に売られた Dycam Model 1）
- しくみ：1975年12月、コダックのスティーブン・サッソンが CCD 画像センサーで白黒の写真を撮り、カセットテープに記録する試作機を作った（売り物ではない）。1988年の富士フイルム DS-1P はメモリーカードに記録したが発売されず、最初に売られたのは1990年の Dycam Model 1（白黒）とされる。今のカメラは、レンズで集めた光を画像センサーで数え、チップで写真に直してフラッシュメモリーに保存する。
