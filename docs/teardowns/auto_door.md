# 分解シート：自動ドア（[P-36]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。出典は各ノードの本物欄

- 年：1931（スタンレー社の光で開く扉）〜1954（ヒューイットとホートンの自動引き戸）〜1960（初の販売）
- しくみ：1931年、スタンレー社の技師レイモンドとロビーが光のしかけで開く扉を作り、コネチカット州のレストランに付けた。1954年、テキサス州コーパスクリスティのガラス店で働いていたリュー・ヒューイットとディー・ホートンが、風で開き戸が壊れるのを防ぐため自動の引き戸を考えた。1960年に売り出された。
