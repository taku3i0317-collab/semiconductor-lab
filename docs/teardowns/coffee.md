# 分解シート：コーヒーマシン（エスプレッソ）（[P-31]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。出典は各ノードの本物欄

- 年：1901（ベッツェラの特許・蒸気式 約1.5気圧）〜1948（ガッジアのレバー式 約9気圧）。豆をひくところから全部やる全自動は1980年代から
- しくみ：細かくひいた豆に、約90℃のお湯を約9気圧で25〜30秒押し通して濃いコーヒーを取り出す。全自動機は、ミル（豆ひき）・ヒーター・ポンプ・抽出ユニット・マイコンを1つの箱に入れ、ボタン1つでひく→詰める→押す→かすを捨てるまでを行う。
