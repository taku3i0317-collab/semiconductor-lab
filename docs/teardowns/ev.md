# 分解シート：電気自動車（EV）（[P-03]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。出典は各ノードの本物欄

- 年：1890年代（初期の電気自動車）〜2008〜今
- しくみ：既存のモノ [P-03] の部品を、使われている技術ごとに番号付けした。電池の電気をインバーターで交流にしてモーターを回し、減速するときはモーターを発電機にして電池に戻す。

|---|---|---|---|

| 駆動モーター | [4-21] ブラシレス DC モーター<br>[1-35] ネオジム磁石<br>[4-22] 誘導モーター（交流モーター） 🆕 | ある | ネオジム磁石の同期モーターが多い。磁石を使わない誘導モーターの車もある |
| インバーター | [9-41] パワー半導体とインバータ<br>[10-14] マイクロコンピュータ | ある | 電池の直流を、モーターを回す速さに合った交流に変える |
