# 分解シート：エアコン（ヒートポンプ）（[P-29]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。生成元：調べ係の確認（出典は各ノードの本物欄）

- 年：1902（キャリアの空調）〜1981（東芝が家庭用インバーターエアコンを量産）
- しくみ：エアコンは冷たさを作るのではなく、冷媒というガスを圧縮・液化・膨張・蒸発させて、部屋の熱を外へ運ぶ（暖房のときは逆に外の熱を部屋へ運ぶ＝ヒートポンプ）。1981年、東芝が圧縮機のモーターの速さをインバーターで変えられる家庭用エアコンを世界で初めて量産し、IEEE マイルストーンに選ばれた。
