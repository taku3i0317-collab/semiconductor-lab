# 分解シート：マイク（ダイナミック・コンデンサー・MEMS）（[P-28]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。生成元：調べ係の確認（出典は各ノードの本物欄）

- 年：1876〜78（炭素マイク）〜1962（エレクトレット）〜2003（MEMS マイク）
- しくみ：マイクは音（空気のふるえ）で薄い膜をゆらし、その動きを電気に変える。ダイナミックマイクは磁石のそばのコイルが動いて電気を起こし（スピーカーの逆）、コンデンサーマイクは膜と板のすき間の変化を電気にする。1962年にベル研究所でできたエレクトレットマイクは、電気をためたままの膜を使うので小さく安く、スマホではさらにシリコンを削った MEMS マイク（2003年に市販）が使われる。
