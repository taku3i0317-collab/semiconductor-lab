# 分解シート：路線バス（ディーゼル）（[P-37]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。出典は各ノードの本物欄

- 年：1895（最初のガソリン機関のバス）〜1920年代（ディーゼルのバス・トラック）〜今
- しくみ：エンジンで走るバスは19世紀末のドイツで始まり、燃費のよいディーゼル機関が大型のバスやトラックに広がった。今の路線バスは、ターボ付きディーゼル・自動変速機・空気ブレーキ・排気の浄化装置を組み合わせている。
