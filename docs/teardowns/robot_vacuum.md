# 分解シート：ロボット掃除機（[P-32]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。出典は各ノードの本物欄

- 年：1996〜1997（エレクトロラックス『トリロバイト』の試作の公開）〜2001（同・発売）〜2002（iRobot『ルンバ』発売）
- しくみ：車輪で床を走りながら、回るブラシでごみをかき集め、ファンで吸いこむ。ぶつかりセンサー・段差センサー（赤外線）で家具や階段を避け、電池が減ると自分で充電台に戻る。新しい機種はレーザーやカメラで部屋の地図を作り、順番に走る。
