# 分解シート：タワーファン（羽根の見えない扇風機）（[P-33]）

S-004（分解による網羅チェック）。部品 → 使われている技術 → ネットワークにあるか。「🆕」は S-004 で足したノード。出典は各ノードの本物欄

- 年：1893（横流ファンの特許）〜1981（羽根のない扇風機の最初の特許・東京芝浦電気、製品にはならず）〜2009（ダイソンの空気増幅式）
- しくみ：よくある縦長のタワーファンは、中に細長い円筒形の『横流ファン（クロスフローファン）』が入っていて、横から吸って前の細いすき間から平たい風を出す。輪っか形の『羽根のない扇風機』は、台の中の羽根車で作った速い風を輪のすき間から薄く吹き出し、コアンダ効果でまわりの空気を巻きこんで風の量をふやす。
