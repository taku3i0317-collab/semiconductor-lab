## なぜ作り直すか
ユーザー（10-21）「めちゃくちゃ使いにくい・見にくい」。相談役が見つけた問題：
- 同じ物に**ウィキのページとノードのページの2つ**がある
- ボタン・見方が増えすぎて、全体がバラバラ（数えた：図のメニューに切り替え・ボタン 16、ノードのページ〈CZ 法〉に見出し 14・押せる物 約 130）
- ウィキの頭に作る側の説明（wiki_export.json …）、機械 74 が並ぶだけで章の分けが無い
- バニラの材料が英語の ID（coal・sand）、レシピの図の矢印と字がずれる
- 機械のページは大きな 3D が先で、「何をする物か」が後

## 決まり（この5つだけ）
1. **1つの物に1つのページ**。上から順に、いつも同じ：
   1. **これは何か**：絵・名前・年と分野・**一言**（へえ①）・ボタン2つ（▶ できるまで／共有）
   2. **どうやって手に入れるか**：ゲームで「作る／拾う・掘る／まだ無い（歴史だけ）」
   3. **作り方**：レシピの図（入る物のアイコン → 作業台・機械・電気・秒 → 出る物）。字とアイコンは同じ格子にそろえる
   4. **本当の歴史**：短い本物の話＋「もっと読む」（へえ②〜④・人物・出典はたたむ）
   5. **つながり**：「これを作るのに要る」「これで作れるようになった」をアイコンで。**中心図はここから1つのボタン**
   - パソコンは2列（左＝1〜4、右＝つながり）、スマホは1列
2. **入口は「探す」と「道案内」**：いちばん上は大きな検索、その下に道案内（はじめての1時間・AI チップまで）、章から、地図で見る（年の図・ランキング）
3. **一覧は章ごと・作れる順**（前提が先）。章＝分野（生きる道具・金属・化学・熱・電気・真空・ガス・光・精密・半導体・制御…）
4. **バニラの材料は日本語の名前**（自分たちで書いた 49 語の小さな辞書。ゲームの言葉のファイルは写さない）。絵は使わない（頭文字の点線の四角）
5. **ボタンは最小限**：各ページに「▶ できるまで」「共有」「中心図で見る」の3つだけ。English・ふりがな・誤りを知らせる は下に小さく

## 今の機能：残す・まとめる・消す
| 今 | どうする |
|---|---|
| ノードのページ nodes/<番号>.html | **残す＝物のページの本体**（上の5つの順に組み直す） |
| ウィキのアイテムのページ wiki/items/*（860） | **ノードのページにまとめる**（その物のページの「手に入れ方・作り方」へ）。前の URL は案内のページ（新しいページへ移る） |
| ウィキの機械のページ wiki/machines/*（74） | 機械もノードの物として**物のページ**に。3D は「作り方」の下に小さなボタン |
| ノードの無いアイテム 82 | いちばん近いノードに入れる（案を作ってユーザー／担当と決める） |
| ウィキの入口・道案内 | **入口（index）にまとめる**。作る側の説明は消す |
| 年の図（network.html）・メニューの切り替え・ボタン 16 | **「地図で見る」1つ**に。切り替え（すべての技術・今すぐ作れる・なぜ動くかの線・つながりで見る）は図の中の小さな「見え方」1つに |
| 中心図・ムービー | 残す（物のページの「つながり」と「▶ できるまで」から） |
| ランキング・人物・用語集・影響を受けた作品 | 残す（入口の下とページの下の小さなリンク） |
| 目次・へえ①〜④の並び・確かさの欄・ゲームでの作り方（文）・影響・さかのぼる・ここにたどり着くには | **たたむ**（「もっと読む」と「道案内」へ） |
| 見本 S-041・S-042・S-043・S-048・S-049 | いったん置く（作り直しの後に、要る物だけ） |
| シェア・PWA・ふりがな・英語・sitemap・構造化データ・CC0 | そのまま |

## URL が切れないように
- 物のページは今と同じ `nodes/<番号>.html`（検索に登録済み）
- `wiki/items/<名前>.html`・`wiki/machines/<名前>.html` は、短い案内のページ（すぐ `nodes/<番号>.html#<名前>` へ移る、canonical も新しい方）
- `node.html#番号`・`network.html` はそのまま開ける

## 作る順（OK の後）
1. 物のページの形（5つの順）を作り、ウィキの中身（レシピ・手に入れ方）を入れる → 3つの物で見てもらう
2. 入口・章の一覧・検索
3. ウィキの古い URL を案内のページに、sitemap を直す
4. 図のメニューを「地図で見る」1つに
- 毎回、スマホとパソコンの写真で確かめる（360・390・430・パソコン）
