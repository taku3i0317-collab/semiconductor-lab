# S-048 見本「分野の泡」— なぜこの形にしたか

見本：docs/mockups/S048.html（`?id=番号`、本物のデータで動く）。写真：S048_phone.png（スマホ：はじめ・泡を開いた所・物を選んだ所・電卓）、S048_pc.png（パソコン）。**本番は変えていない**。

## 考えたこと
- 今の中心図は「全部の丸を一度に」出すので、スマホでは 300 の点と 1,000 本の線になり、子どもには**何を見ればいいか分からない**。どれだけ並べ方を工夫しても、点が小さすぎて名前が読めない
- 子どもが知りたいのは「スマホって、どんな物からできているの？」「いちばん遠い始まりは何？」。だから**まず数を少なく（分野の泡 10〜16 個）**、押したら中が**字で読める**ようにした

## 形
1. **真ん中にモノ、まわりに分野の泡**（冶金・化学・電気・光・半導体の工程…）。泡の大きさ＝その分野の技術の数、泡の中の絵＝その分野でいちばん大事な物（PageRank）、緑の数＝その分野にある「始まり」の数
2. **時計回りに昔へ**：上が新しい分野（半導体・通信）、まわるほど古い分野（冶金・道具・農業）。分野の年はその分野の技術の年の真ん中の値。泡の並びが歴史の時計になる
3. **線は泡どうしだけ**（太さ＝つながりの数、ふだんはうすい）。オレンジの線＝真ん中のモノに**すぐ要る**物がある分野
4. **泡を押す** → 下から（パソコンは右から）中の一覧：作る順（始まりが先）、アイコン・名前・年、「始まり」「すぐ要る」の印。**名前が全部読める**
5. **一覧の物を押す** → へえ①（ふりがな・英語）と、**真ん中までの道**を字で：「スマホ ← 光ファイバー」「スマホ ← … ← CZ 法 ← … ← 珪石」。ボタン：◎ これを真ん中に（泡がふわっと入れかわる）・▶ できるまで（今のムービー）・詳しく
6. **「わかる／全部」**：全部＝今の中心図（ぜんぶの丸）。くわしく見たい人はそちら
7. ← で前の真ん中へ。URL（?id=）で同じ物が開く

## 守ったこと
- 数は全部データから数える（技術の数・始まりの数・分野の数・泡の数）。作った数は無い
- 軽い：最初の絵まで 0.44 秒（スマホ 390×844）。くわしい文（1.5MB）は絵の後で読む
- 動きを減らす設定：入れかわりのふわっと・シートのすべりを止める。キーボード：泡は Tab と Enter で開く、Esc で閉じる
- ふりがな（シートの字に）・英語（EN ボタン）・CC0・人の肖像なし

## 気になる所・次にできること
- 分野は TECH_TREE の幹（16）そのまま。「知恵（考え方・発見）」が大きな泡になる（スマホで 39）。子ども向けに分野をもう少しまとめる（例：幹を 8 つの大きな仲間に）こともできる
- 泡の中は一覧（字）にした。泡の中を小さな輪にする形も作れる
- 「全部」から戻ると、また泡の形に戻る
