## [B-12] 太陽電池（IMP-25、v0.2b のゴール）

## [B-02a] ダゲレオタイプ（IMP2、S-002）
- [x] 自動✅ 露光の量の計算（60秒・日なたで 100％、雨 30％）、うすい／ちょうどよい／黒い、感光板だけがカメラに使える、水銀で現像・塩/ハイポで定着してデータを引き継ぐ、感光板なしではカメラが開かない、lang `(daguerreotype)`
- [ ] 人間：昼の空の下で感光板を左手、カメラを右手で右クリック長押し → 離すとチャットに秒数と露光の量、板が「露光した板」に。屋根の下・夜・雨で写りが変わるか。完成した写真のツールチップ（場所・時刻・露光）。押している間の構え（望遠鏡のポーズ）

## [B-02b] ゼラチン乾板とネガ（IMP2、O-008）
- [x] 自動✅ 乾板 1秒（銀板 60秒）で 100％、硫酸鉄(II)で現像・水銀では不可、ハイポでネガ、ネガ＋印画紙 → 紙焼き 3枚（ネガは中身ごと戻る）、印画紙のレシピ（塩＋硝酸銀）、乾板を持つとカメラが開く、lang `(dry_plate_negative)`
- [ ] 人間：感光乾板を左手・カメラを右手で約1秒押して離す → 露光した乾板。作業台で現像・定着 → ネガ。ネガ＋印画紙を何回も → ネガが戻って紙焼きが増えるか。紙焼きのツールチップ（場所・時刻・露光）
