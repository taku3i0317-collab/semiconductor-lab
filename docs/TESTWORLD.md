# 試験場（S-001、IMP3）

ゲームの中で、機械やアイテムをまとめて確かめるための建物。ワールドのファイルは git に入れず、コマンドで毎回建てる。

## 使い方
1. 新しいワールドを作る（ゲームモード：クリエイティブ、コマンド：有効。平らなワールド「スーパーフラット」が建てやすい）
2. 広くて平らな所に立って、チャットで `/function semiconductor-lab:testworld`
3. 足元から東と南に試験場ができる（大きさは testworld.mcfunction の先頭に書いてある）。今いる所の空気・床は上書きされる

## 見方
- **列＝幹**（石器時代・冶金・化学・熱・電気・真空・ガス・光学・精密・半導体…）。列の西の端の看板に幹の名前
- **区画＝ノード**：北側の看板に「[ノード] 題」と、TEST_QUEUE の「人間が見る」項目の始め（全文は下の一覧）
- 区画の東のチェストに、そのノードのアイテムと、機械の材料（クリエイティブなので足りなければ増やせる）
- 電気を使う機械の真下のピンクと黒のブロックは **試験用の無限電源**（1 MW、燃料なし、クリエイティブ専用・レシピなし）。本物の発電ではない
- **最後の列は本物の発電**：蒸気機関に石炭と水バケツを入れると、銅ケーブルを通って電気炉が動く（試験用の電源は使わない）
- 海辺が要る塩田、流れる水が要る水車などは、置いただけでは動かない（看板の「見ること」を読む）

## 作り直し
機械・アイテムを足したら `python tools/gen_testworld.py`（machine_recipes.json・TEST_QUEUE の部品・タブの並びから作る）。
GameTest `testworld` が「関数が最後まで動き、置いた物が正しい」ことを確かめる。
