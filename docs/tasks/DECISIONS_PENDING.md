### [3-12] 耐火れんが

- **Q3-2 結合材**：本物のディナスれんがは石灰約2%。指示どおり粘土で実装し、placeholder で「石灰[0-10]未実装のため粘土」と明記（粘土結合の珪石質れんがも実在）
- **Q3-3 [3-08] の🔧を外した**：指示どおり ✅ にした。ただし「銑鉄＝鉄インゴット」の近似は残る（[1-09] 待ち）。見出しに注記済み
- **Q3-4 焼成は溶鉱炉のみ**（かまどでは焼けない）。溶鉱炉＝高炉の近似（#37）なので「≈1450℃」として扱った

### [1-27] 鉛
- **Q27-1 還元剤**：PbO + C → Pb の炭素を「かまどの燃料」とみなし、材料に木炭を書かなかった（かまどは1入力のため）。GeO2+木炭（作業台で混ぜる）と流儀が違う。仮決定の理由：作業台で混ぜるだけだと「熱」が消えるため。溶岩バケツ燃料でも還元できる点は CHEMISTRY #56 に明記。木炭を混ぜた「装入物」アイテムを挟む方がよければ直します
- **Q27-2 SO2 副産物**：かまどは1出力なので未回収（#15 と同じ）。v0.2b の精錬炉（多出力）で回収予定

### [1-28] タングステン線
- **Q28-1 WO3 の作り方は「仮」**：本物はソーダ融解→塩酸でタングステン酸→焼成。ソーダ[2-03]・塩酸[6-06]が未実装なので「かまどで焼くだけ」にして placeholder で未実装を宣言（硫酸で代替する案は化学的に不適切なので採らなかった）
- **Q28-2 新ブロック「水素炉」を作った**：還元と焼結の2工程を1台で（材料で工程が決まる）。電気炉[4-12]が未実装なので「電力＝熱」の近似を placeholder に明記。将来 GeO2+H2→Ge（ROADMAP #6）もこの炉に足せる
- **Q28-3 線引きは作業台**（焼結棒1→線4）。スエージング機・ダイスは省略（placeholder）。ダイヤモンドを材料にすると毎回消費されて不自然なので入れなかった
- **Q28-4 電力・時間**：還元 3kW×30秒、焼結 10kW×20秒（ゲームバランス）。焼結は 10kW 必要で、3kW しか来ないと約3割の速さでしか進まない（ConsumerBlockEntity のバッファ仕様）
- **Q28-5 機械ブロックの共通化**：block/ConsumerMachineBlock（向き＋LIT＋GUI）を新設し、水素炉・圧縮機で使用。電解槽・転炉は既存のまま（動いているので触っていない）
