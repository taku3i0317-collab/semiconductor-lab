# 09：塩素の鎖 [6-04][0-16]→[6-05]→[6-06]→WO3本物化・[1-34]GeCl4
## 1. [6-04] 岩塩鉱：新鉱石、乾燥バイオーム（砂漠/荒野）の地下。岩塩（原石）→塩。[0-16] 塩田ブロック：海/浜バイオームでのみ動き、時間で海塩＋にがり（MgCl2）。へえ①「岩塩は石になった海」
## 2. [6-05] クロルアルカリ電解：電解槽に第2モード（塩＋水＋電力→塩素（ガスホルダー対応）＋水素＋水酸化ナトリウム）。隔膜は省略と明記（1890年代）。ガスホルダー/圧縮機/ボンベに塩素を追加（塗色：日本規格は黄）。へえ①「塩から塩素と苛性ソーダが同時にできる」
## 3. [6-06] 塩酸：水素＋塩素→燃焼→塩化水素→水に溶かす（ガラス瓶）。機械は酸水素バーナー[7-02]の派生でよい
## 4. WO3 を本物に：鉄マンガン重石→ソーダ[2-03]融解→塩酸でタングステン酸→焼成→WO3。tungsten_trioxide.placeholder 削除、CHEMISTRY 該当行 ✅
## 5. [1-34] GeCl4 蒸留精製：GeO2＋塩酸→GeCl4→蒸留（石英管）→加水分解→高純度GeO2。既存の「精鉱＋硫酸→GeO2」は残しつつ、精製炉の純度上限を「GeCl4 経由の GeO2 なら 10N、硫酸経由なら 9N」に（CHEMISTRY の「精製炉が肩代わり」の省略を解消）
