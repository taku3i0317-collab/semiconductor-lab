# 07：[0-10] 生石灰 → [3-06] 焙焼炉（2出力、SO2回収）
## 1. [0-10] 生石灰：方解石（バニラ calcite）または石灰石近似（バニラ stone は不可。calcite/ tuff は不可、calcite のみ）→かまど→生石灰（CaCO3→CaO+CO2、約900℃）。[0-11] 消石灰（生石灰+水、発熱）も1行で。耐火れんがの結合材を粘土→石灰に戻し placeholder を外す。へえ①「貝殻を焼くとできる。壁の漆喰の元」
## 2. [3-06] 反射炉を「焙焼炉」として実装：2入力（鉱石＋燃料/電力）2出力（金属酸化物/金属＋SO2）。方鉛鉱→一酸化鉛＋SO2、辰砂→水銀＋SO2、閃亜鉛鉱→酸化亜鉛＋SO2（亜鉛は既存かまどレシピも残す）。SO2 は既存の二酸化硫黄アイテムで出し硫酸ルートへ。CHEMISTRY #15 #16 #56 と Q145-2 の「未回収」を解消。へえ①「鉱石を焼くと硫黄が煙になって出ていく。昔は毒の煙だったが、集めれば硫酸になる」
## 3. 閃亜鉛鉱の Ge精鉱/インジウム分割（#16）も焙焼炉の副産物スロットで同時出力に置換（1回で亜鉛酸化物+Ge精鉱+In少量+SO2）
