## 2. 幹2 化学（35ノード前後）
既存：[2-01]硫酸 [2-02]カリ [2-10]フッ酸。追加の骨格：
ソーダ（天然トロナ→ルブラン法1791→ソルベー法1861）／石鹸（油脂+アルカリ、古代〜）／硝酸・硫酸・塩酸は幹6の既存を参照／
硫化水素・硫酸塩／炭酸カルシウム系／ガラス原料としてのソーダ石灰（幹7へ）／
有機化学：[2-20]コールタール（コークス副産物、1850〜）→ベンゼン・フェノール→
フェノール樹脂（ベークライト1907）→ 感光性樹脂（ゴム系ネガレジスト1950年代イーストマン・コダックKPR→ノボラック系ポジレジスト1970年代）= フォトレジストの系譜（第3章の背骨）／
石油化学（原油→蒸留→エチレン→ポリエチレン1933）⚠️範囲／溶剤（アセトン、エタノール発酵+蒸留）／
純水（蒸留→イオン交換1935→超純水）＝半導体洗浄の背骨／王水／過酸化水素（1818テナール、RCA洗浄に必須）／アンモニア水／
各ノードにマインクラフトでの入手案を1行。年・人名・反応式必須、⚠️可。

## 3. 幹3 熱・炉（15ノード前後）
既存：[3-10]アチソン炉 [4-12]電気炉（抵抗）。骨格：
たき火→かまど（バニラ）→窯[0-15]参照→ふいご（送風、温度上昇）→溶鉱炉（バニラblast furnaceを「高炉」の近似にしてよいか⚠️）→反射炉（1700s）→るつぼ炉→転炉（ベッセマー）→
温度計測（熱電対1821ゼーベック、光高温計）→断熱材（耐火レンガ、珪藻土、石綿⚠️健康問題）→
誘導加熱炉（既存の帯域精製炉を参照）→アーク炉（1900頃、金属Si・カーバイド）→真空炉（幹5前提）→温度の階層表（何℃で何ができるか）を節の冒頭に。
