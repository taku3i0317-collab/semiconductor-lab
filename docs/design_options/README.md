# デザイン案（NET-09）

ウェブ（docs/network.html・docs/node.html）の見た目をそろえるための案。**選ぶまでは、ふだんのページは変えない**（案は URL に `?design=A` などを付けたときだけ効く）。
選ばれた案を docs/DESIGN_SYSTEM.md にルールとして書き、両ページに適用する。

## 2. デザイン案（スクリーンショット）

同じ4つの画面を、いま（now）と案 A・B・C で撮った：`<案>_1_network.png`（最初の画面）・`_2_smartphone_card.png`（スマホを押したカード）・`_3_node_ai.png`（AI のページ）・`_4_node_mobile.png`（スマホの幅で電磁誘導のダイナモのページ）。
ブラウザで見るときは URL に `?design=A`（B・C）を付ける（例 network.html?design=A）。付けなければ今のまま。

どの案も同じ決まり：
- 文字は BIZ UDPゴシック（Google Fonts から読む。フォントのファイルはリポジトリに入れない：SIL OFL で CC0 とは別のため）。ドット風の書体（DotGothic16）は案 B・C の見出し・モノの名前だけ
- 色は意味のある所だけ：技術は1色（✅ は塗り、❓ は輪だけ）、モノと発見だけ色を付ける。幹の17色と、線の年の差の色分けはやめた（幹は帯の名前で）
- アイコン・絵文字は単色のドット絵（仮：今のアイコンを形だけ1色にしたもの）
- 部品の大きさ：ボタンの高さ 36px、カードの内側の余白 16px、見出し 18／16／13px、余白は 4・8・12・16・24px の段、角の丸みは案ごとに1つ

| 案 | どんな見た目 | これを選ぶと何が良いか |
|---|---|---|
| A シンプル・白基調 | 白地・灰色の文字・青（モノ）と紫（発見）だけ | いちばん読みやすく印刷にも向く。授業や教科書で使うなら A |
| B 少しゲーム寄り | 暗い紺の地・黄色（モノ）・角ばった枠・見出しとモノの名前がドット風 | MOD の世界とつながって見え、子どもがわくわくしやすい。長い文は A・C より少し読みにくい |
| C 中間 | 生成りの紙・青緑（モノ）・大きな見出しだけドット風 | 落ち着いて読めて、少しだけ遊びの気配がある。図鑑や本の雰囲気にしたいなら C |
