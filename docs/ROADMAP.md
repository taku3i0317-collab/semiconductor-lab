## 章の進め方（固定）
1. 先行調査：その章のAPIを javap でまとめて API_26X.md へ
2. 設計の決定（議論は最初にまとめて）
3. 実装（80行ルール／1Java=1スクリプト／機械はテンプレートで生成）
4. 化学レビュー → CHEMISTRY.md / SOURCES.md 更新
5. git tag vX.Y ＋ gradlew build で jar を保存（公開はしない）

## 作業ルール（2026-10-19 更新）
- スクリプトは1本80行以内。Java 1ファイルにつき1本
- 新しいAPIは jar を javap で調べてから書く（推測禁止）→ API_26X.md に記録
- パスは全部フルパス。最後に確認出力
- 新バニラ要素はゲーム内で名前確認してから使う
- 「仮」は代用ではなく未実装宣言。ゲーム内ツールチップ＋CHEMISTRY.md に明記
- テクスチャ・Shift解説・公開は「仕上げフェーズ」まで仮のまま
