## #7.5 化学レビュー（2026-10-19）
- 🔴 純度上限 11N は Si の数字。Ge は 10N 程度 → 修正予定（6N→9N→10N）
- 🔴 ドーピングを作業台で固体混合しているのは誤り。溶融状態で入れる＝精製炉でゾーンレベリング（Pfann）→ 炉に第2スロットを追加して置換予定
- 🔴 表面汚染・エッチング工程が存在しない。v0.1 はツールチップで明記、v0.2b でエッチング槽
- 🟢 クリーンルームは第1章には歴史的に不要（層流CRは1960年代）。第3章で「なぜ必要になったか」、第5章で歩留まり実装
- 🟡 SO2+水は亜硫酸。SO3酸化の省略を明記済み／塩素なしのため硫酸浸出／リンは初期の実際とは異なる可能性
