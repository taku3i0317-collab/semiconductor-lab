| # | レシピ | 本物の反応・工程 | 判定・省略した点 |
|---|---|---|---|
| 1 | 石炭 →かまど→ 石炭灰 | 石炭の燃焼。灰にGeが濃縮 | ⚠️ Ge濃縮石炭は限られた産地のみ ❓産地・含有量 |
| 2 | 石炭灰 ×8 → Ge精鉱 | 灰からのGe回収（濃縮） | ⚠️ 本物は塩酸浸出・塩化物蒸留など複数段。「濃縮」の1段にまとめた |
| 3 | 尖った硫黄 / 硫黄ブロック → 硫黄の粉 | 天然硫黄（火山性）の粉砕 | ✅ |
| 4 | 硫黄の粉 + 水 → 硫酸 | 接触法：S + O2 → SO2 ／ 2SO2 + O2 →(V2O5)→ 2SO3 ／ SO3 + H2O → H2SO4 | ⚠️ 3段を1段に。触媒V2O5・酸素を省略 |
| 5 | Ge精鉱 + 硫酸 → GeO2 | 酸浸出 → 加水分解で GeO2 | ⚠️ 本物は塩酸で GeCl4 にして蒸留精製してから加水分解。塩素がバニラにないため硫酸で代替 ❓妥当性 |
| 6 | GeO2 + 木炭 → 金属Ge(98%) | GeO2 + 2H2 → Ge + 2H2O（工業は水素還元）／ GeO2 + C → Ge + CO2 も可 | ⚠️ 炭素還元で表現。工業的には水素 |
| 7 | 粗Ge → 精製Ge（仮） | 帯域精製（Pfann 1952）：溶融帯を移動させ偏析で不純物を端に集める | ⚠️ #6 で精製炉に置換。純度段階 98%→6N→9N |
| 8 | 骨粉 + 砂 + 木炭 → リン | ヴェーラー法：2Ca3(PO4)2 + 6SiO2 + 10C → P4 + 6CaSiO3 + 10CO | ⚠️ 本物は約1500℃の電気炉。温度・量比を省略 |
| 9 | 精製Ge ×8 + リン → n型Ge ×8 | リン（5価）ドーピング → 電子過剰 = n型 | ⚠️ 本物は ppm〜ppb オーダー。8:1 は「微量」の象徴 ❓初期Geトランジスタの実際のn型ドーパント（Sb/As が多い） |
| 10 | 精製Ge ×8 + インジウム → p型Ge ×8 | インジウム（3価）ドーピング → 正孔過剰 = p型 | ⚠️ 同上 |
| 11 | 金塊2 + n型Ge + 銅 → 点接触型トランジスタ | n型Ge板に金の針2本（エミッタ・コレクタ）、底面にベース電極（1947） | ✅ 構造は本物どおり ❓年号・ドーパント |
| 12 | [In][n型Ge][In] + 銅 → 未焼成 | 合金接合型の組み立て | ✅ |
| 13 | 未焼成 →かまど→ 合金接合型トランジスタ | 加熱でInが溶けGeに拡散、両側がp型化 → p-n-p接合（1952） | ✅ 原理どおり。温度（約500℃）は省略 |
| 14 | 合金接合型 ×3 + 鉄 + 銅 + RS → ラジオ | 3〜6石トランジスタラジオ（1954〜） | ⚠️ 製品の部品はバニラ素材で簡略化 |
